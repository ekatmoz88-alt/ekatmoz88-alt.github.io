# CAD-надстройка · Справочник команд

Обезличено. Имена команд иллюстративны.

## `zeiss`
Подпись координат X/Y/Z у выбранной точки.

| Аргумент | Тип | По умолчанию |
|----------|-----|--------------|
| `pt` | точка | — |
| `height` | вещ. | 0.1 |

Ошибки: нет точки → `*error*`, восстановление OSNAP.

## `coord`
Пакетная нумерация точек + экспорт.

| Аргумент | Значения |
|----------|----------|
| `mode` | `"sdr"` \| `"gre"` |

Выход: `.sdr` (Sokkia), `.gre` (Leica). Пустая выборка → сообщение, файл не создаётся.

## Локализация
