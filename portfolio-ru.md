# Портфолио · Технический писатель (RU)

**Кейс 1 · Automotive Infotainment API (MIB3)** — REST/WebSocket ViWi/RSI спецификации данных для навигационного ядра Volkswagen (сервисы guidance, maprenderer, navdata). Схемы ограничений, CRUD-матрицы и обработка асинхронных уведомлений. [См. спецификацию →](vwa-navigation-spec.md)

**Кейс 2 · FilmMgr** — Инструмент расчёта оптических покрытий (Delphi). Документирование алгоритмов многомерной численной оптимизации (случайный поиск + метод Пауэлла). Формализация физико-технических ограничений среды: подложки (CaF₂, BaF₂, Ge), диапазоны длин волн и поляризация света (S/P). Оформлено в endpoint-стиле (Input → Constraints → Output) с фиксацией известных багов ядра (Known Issues). [См. схему и legacy-документацию →](filmmgr-schema.md)

**Кейс 3 · CAD-надстройка (AutoLISP)** — Команды для пакетного нанесения координатных меток. Оформлено как command reference.

**Кейс 4 · АРМ учёта досье** — Специализированное ПО для учёта документов (ЕСКД). 10 состояний синхронизации.
