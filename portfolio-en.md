## Selected projects

### 2. PPO Territory / Deshifrator / UMMS — Unified Technical Documentation
A consolidated documentation hub for one connected historical project contour. It brings together the PPO Territory information system and its passport-accounting information base, the Deshifrator document-processing workstation, and UMMS as a related system boundary. These retain distinct application, system, and runtime boundaries; the hub is a documentation collection, not one executable product.

The materials cover Oracle database inventory and data models, the 401-table grouping with arithmetic verification, the separate 381-entry physical-structure document, logical subject areas, API/source mappings, workstation requirements and architecture, ModuleMobile/ModuleStationary/PassportPaint source-based review, file exchange, SQLite, SOAP/WSDL, and FIAS/Elasticsearch dependencies. Historical labels «Дискриптор» and «Дешифратор» refer to the same workstation project.
