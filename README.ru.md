# Веб-хаб портфолио технического писателя

[English](README.md) | [Русский](README.ru.md)

Репозиторий содержит исходники публичного сайта-портфолио на GitHub Pages. Это веб-хаб портфолио, а не React/Vite-дашборд GitHub-профиля и не репозиторий спецификаций API.

## Опубликованные страницы

- [Сайт портфолио](https://ekatmoz88-alt.github.io/)
- [Портфолио на английском](https://ekatmoz88-alt.github.io/portfolio-en.html)
- [Портфолио на русском](https://ekatmoz88-alt.github.io/portfolio-ru.html)
- [Интерактивный GitHub-дашборд](https://github-profile-dashboard-vite.vercel.app/)
- [Двуязычный аудит репозиториев](https://github-profile-dashboard-vite.vercel.app/portfolio-audit.html)

## Содержимое репозитория

- `portfolio-en.md` и `portfolio-ru.md` — двуязычные материалы портфолио.
- `projects/` — страницы проектов и вспомогательные материалы.
- `src/`, `index.html`, `vite.config.js` — исходный код сайта и конфигурация сборки.
- `filmmgr-schema.md`, `mib3-navigation-api.md` — технические материалы портфолио.

## Границы проекта

Сайт представляет выбранные работы технического писателя и ссылается на самостоятельные репозитории. Он не является источником архитектурной истины: техническое содержание хранится в репозиториях соответствующих проектов.
