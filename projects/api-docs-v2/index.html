Инструменты и workflowTooling & workflow

OpenAPI 3.1 · YAML · Redocly CLI · Spectral · Markdown · Git · Jekyll · HTML/CSS · GitHub Actions · Node.js · npm

Workflow GitHub Actions устанавливает зависимости, выполняет проверки аудита зависимостей, валидирует обе OpenAPI-спецификации с помощью Spectral и Redocly, собирает сайт Jekyll и публикует Pages artifact из main.

The GitHub Actions workflow installs dependencies, runs dependency audit checks, validates both OpenAPI specifications with Spectral and Redocly, builds the Jekyll site, and deploys the Pages artifact from main.

Это портфолио/demo-проект. Orders API использует примеры и иллюстративные данные; SOAP case studies не означают доступ к действующей клиентской системе.This is a portfolio/demo project. The Orders API uses illustrative endpoints and data; SOAP case studies do not imply access to a live customer system.
