НазначениеPurpose

Dashboard собирает ссылки на пять репозиториев, краткие описания, тематические теги и ссылки на опубликованные сайты там, где они указаны в данных приложения.

The dashboard brings together links to five repositories, short descriptions, topic tags, and published site links where provided in the application data.

Технологии и реализацияTechnology & implementation

React 18 · Vite · React Router DOM

Данные карточек репозиториев заданы в src/App.jsx: название, описание, теги, URL репозитория и, если есть, URL сайта. Dashboard отображает эти данные в карточках с переходами на GitHub и опубликованные страницы.

Repository card data is defined in src/App.jsx: name, description, tags, repository URL, and, where available, site URL. The dashboard renders this information as cards linking to GitHub and published sites.
